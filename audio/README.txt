音乐文件放置说明
================

请把你合法拥有/获得授权的音乐文件放到这个目录下。

需要的文件：
1. birthday-song.mp3    生日歌（开场播放）
2. we-met-before.mp3    我们好像在哪里见过（小时候STAGE片段）
3. yu-jian.mp3          遇见 - 孙燕姿（其余所有部分）

修改歌曲路径：
打开 js/content-map.js，找到 MUSIC_CONFIG 部分，
修改 tracks 里的 src 和 name 即可。

关于版权：
请确保你拥有这些音乐文件的合法使用权。
本项目不包含任何受版权保护的音乐文件。
